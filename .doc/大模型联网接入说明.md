数据库 017_llm_optional_temperature.sql 已本地执行，temperature 允许 NULL，初始化 001/007 同步。已有配置值保留；实体温度字段允许更新为 NULL，渠道启停采用仅更新 enabled 的操作，避免温度更新策略覆盖其他字段。构建、29 项相关独立 JUnit、Node VM 表单测试及差异检查通过；真实 MySQL 事务验证 NULL 写入并回滚。Java 服务必须重启，未做本轮完整页面保存/外部模型联调。以下前缀排除段落是之前实现，已由本条替代。

Responses 生成参数已适配：渠道 maxTokens 映射为 max_output_tokens，temperature 通常随请求发送。OpenAI 策略通过 temperatureExcludedModelPrefixes 对 gpt-5/o1/o3/o4 系列暂不发送随机性（当前没有推理模式配置），不表示这些系列所有模式都不支持；兼容网关及豆包不套用 OpenAI 的排除规则。协议选项接口返回同一份排除前缀供页面使用，不重复维护中文枚举或模型能力表。

页面 bean5：Responses 恢复输出上限及普通模型随机性编辑，OpenAI 已知推理系列仅禁用随机性；Mock/OpenAI Chat 搜索专用模型仍维持不发送原生成参数。后端未提供新排除字段时页面明确要求重启，避免新页面使用旧参数规则。主代码打包、28 项相关独立 JUnit、Node VM 表单测试及差异检查通过，包含本地 HTTP 实际请求体、两种引用回读和厂商规则隔离；未做外部厂商联调，服务需重启，无数据库变更。

依据：[OpenAI 输出 token 与推理 token 说明](https://developers.openai.com/api/docs/guides/reasoning)、[OpenAI GPT-5.2 参数限制](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.2)、[方舟 Responses 创建请求参数](https://docs.volcengine.com/docs/ark/create-model-responses-api?lang=zh)。方舟页面正文需要 JS，本轮参数依据其官方检索索引；具体模型接受情况仍待真实联调。

HTTP 交互已收敛到 [具名 RestTemplate 连接池](共用HTTP连接池.md)：各远程策略按名称注入预注册的 llmRestTemplateWithTimeout，超时和证书配置统一取 application.yml 的 http.llm；渠道中的对应字段不再影响调用，不再使用动态工厂或每次创建 RestClient。

数据库 `geo_llm_channel.strategy_bean_name` 直接保存 Spring Bean 名。路由通过 Spring 注入的 `Map<String, LLMStrategy>` 获取实例，不反射，不手工注册编码，不自动切换策略。

`LLMStrategy`只保留 query 和 protocolType。AbstractChatCompletionsApiStrategy、AbstractResponsesApiStrategy 维护对应协议的基础请求、HTTP、正文与元数据解析；两个通用策略继承默认实现，OpenAI 和豆包子策略在 super.buildRequestBody 基础上调整厂商参数。父类共用 HTTP 连接资源和 LlmCitationParser，不注册为独立策略 Bean。自建策略注册表保持删除。

通用策略可直接在页面选择，用于其已经实现的基础文本协议；不主动添加搜索、文件或其他工具。当前收敛仅保留已有六个 Bean，不新增国内通道、独立搜索接口、网页抓取或搜索资料拼接流程。本次继承重构不再更改 Bean 名；此前重命名仍需依次执行 019、020 SQL，历史快照不改写，旧策略未完成任务需在升级前结束并在升级后重建。

路由使用单次 selectOne（固定 LIMIT 1）定位渠道，直接将数据库实体交给策略，不再复制为 LLMConnectionConfig，也不另行传递密钥。远程空密钥在调用前拒绝，HTTP 请求头读取当前渠道密钥；实体的密钥不参与 toString 或接口响应。已删除无调用的 LangChain4j 方法和三个依赖，测试入口移除两层纯转发，原 HTTP 接口保持不变。

不再维护策略中文名称枚举或 strategyName 响应字段。页面使用数据库渠道名称、模型名称，策略选项直接展示实际 Bean 名和协议，来源为 Spring 注入的策略 Map。

## 当前 Bean

| 数据库保存的 Bean 名 | 实际调用 |
|---|---|
| chatCompletionsApiCommonStrategy | 兼容 Chat 普通问答，不注入搜索参数 |
| responsesApiCommonStrategy | 兼容 Responses 普通问答，不注入搜索工具 |
| chatCompletionsApiOpenAiStrategy | OpenAI Chat；gpt-5-search-api 添加搜索选项 |
| responsesApiOpenAiStrategy | OpenAI Responses，要求 web_search |
| responsesApiDoubaoStrategy | 豆包 Responses，指定 `sources: ["doubao"]` 并要求调用联网工具，使用 SSE 流式读取，收到完成事件后保存完整回答 |
| responsesApiDeepSeekStrategy | DeepSeek 官方 Responses，要求调用 `web_search`（不带 sources），SSE 流式读取；回答无 url_citation，以已打开网页（open_page）作为引用 |
| mockLlmStrategy | 本地模拟，无远程调用 |

供应商标识只作资料，实际行为由选择的 Bean 决定。协议从 Bean 推导并只读展示。Bean 重命名时需同步迁移数据库。

OpenAI/豆包仍需正确的地址、模型、Key 和工具权限。普通兼容渠道不假装联网；Kimi 的独立检索尚未实现，没有空厂商策略。

豆包搜索试用配置：基础地址 `https://ark.cn-beijing.volces.com/api/v3`（策略追加 `/responses`），策略选 `responsesApiDoubaoStrategy`，模型可填写账号已开通的 `doubao-seed-2-1-pro-260915` 或控制台对应调用标识。请求固定 `tools: [{"type":"web_search","sources":["doubao"]}]`、`tool_choice: "required"`；设置 `stream: true`，读取 `response.completed.response` 后解析 `output_text.annotations` 中的 `url_citation`，沿用任务引用与用量入库。需要重启服务加载策略改动；真实模型权限、来源质量和参数兼容性待实际调用验证，非每次调用都保证返回引用。

DeepSeek 联网配置：基础地址 `https://api.deepseek.com`（策略追加 `/responses`），策略选 `responsesApiDeepSeekStrategy`，模型填 `deepseek-v4-pro`。`deepseek-flash`（含旧名 `deepseek-v4-flash`）即使 `tool_choice: required` 也静默不搜索并照常返回成功，2026-10-16 对照实测确认，与地址是否带 `/v1`、temperature、max_output_tokens 无关，不能用于联网诊断。请求固定 `tools: [{"type":"web_search"}]`、`tool_choice: "required"`、`stream: true`。官方 Responses 指南仍写 web_search 被忽略，但 v4-pro 实际返回 `web_search_call`（`search` 只含检索词，`open_page` 含已打开网页 URL，末尾附 `#ws_call_id=`），正文 `annotations` 为空；豆包的 `sources` 被静默去除，`include: ["web_search_call.action.sources"]` 不返回召回列表；该联网能力属于官方未文档化行为，可能变化。Anthropic 兼容接口可返回召回列表但官方标注 citations 忽略，为保持协议统一不接入。

DeepSeek 引用口径（2026-10-16 用户确认）：策略重写父类 `collectStrategyCitations`，将 `open_page` 网址去掉 `ws_call_id` 后按 URL 去重写入引用，标题/摘要/位置为空，页面显示网址；`search` 检索词不计入。含义是"模型实际打开读过的网页"，粒度粗于豆包逐句 url_citation，跨渠道对比引用时需区分。模型只检索未打开网页时引用为 0。入库、接口和页面沿用原引用链路，无改动。单次联网输入约 0.4~3.7 万 token（搜索内容计入输入）。

引用只来自明确的 url_citation，支持扁平和嵌套结构。不把正文 URL 或检索召回来源当成模型引用，没有引用不等于没有联网。
