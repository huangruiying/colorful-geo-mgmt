# 项目数据导入导出验收（2026-10-24）

## 当前结果与边界

- 入口：基础配置 → 数据导入导出，页面 `src/main/resources/static/admin/project-info-import-export.html`。
- 一个项目一个 JSON，格式标识 `colorful-geo-project`、版本 `1`、最大 50 MiB。固定八个数组分区：`project`（恰好一条）、`plans`、`questions`、`planChannels`、`tasks`、`results`、`reports`、`analyses`；字段采用数据库列名，JSON 列保留为 JSON 对象或数组。不是任意表备份或 SQL 执行入口。
- 导出完整项目及诊断链路，不带内容优化、发布记录、渠道连接配置或 API Key。历史渠道名称、模型名及协议保留用于展示；来源任务的 `request_id` 清空。
- 当前方案按当前渠道编码导出；任务、结果及报告按各轮冻结编码导出，支持同一来源渠道改过编码。文件中的渠道外键为 `channel_code`，报告汇总中的渠道引用为 `channelRef`，快照保留 `channelCode`。
- 导入新建项目及所有子记录，不覆盖旧项目；各表自增主键、外键、快照与报告证据标识全部重映射。ID 使用十进制字符串传输，防止浏览器大整数丢失精度。
- 历史问题已从方案删除时，通过当前事务内插入并立即删除临时问题行预留新追溯 ID；不向当前方案追加已删除问题，也不改变历史问题正文。自增序列可能有空隙。
- 有待执行／执行中的任务、结果或报告时拒绝导出；导入也校验终态。失败报告内原有待判定分析可以保留，后台只按报告终态领取，不会单独运行这些分析。
- 导入仅按目标环境已有渠道编码精确匹配；全部缺失项一次提示。匹配渠道在导入事务内加锁，防止校验后被删除或改码。渠道启用状态与凭据仍由目标环境维护。
- 历史渠道快照不含来源连接及生成参数，导入后的历史用于查看；继续诊断应从导入方案创建新任务，不应把旧失败任务当作跨环境续跑任务。
- 同一文件再次成功导入会生成另一个项目副本。页面阻止操作中的重复点击，不自动重发请求；网络中断后提示先查看项目列表。
- 报告中的发布匹配只有网址分类，无发布记录外键；保留冻结分类，不在导入时按目标环境重算。内容优化和发布记录未迁移。

## 实际分层与事务

| 位置 | 实际职责及必要性 |
|---|---|
| `MgmtProjectInfoImportExportController` | 文件 HTTP 接收、体积上限、下载响应、提交后日志和 ProblemDetail；复用全站登录与 CSRF |
| `ProjectInfoImportExportService` | 一致性快照导出、渠道匹配、依赖顺序写入、历史问题 ID 预留及嵌入引用重建；原 References 类已取消，业务操作收回此服务 |
| `ProjectInfoImportExportBusiness` | 应用层负责文件大小、文件 JSON 输入输出及导入 Response 组装，不直接操作数据库 |
| `ProjectInfoImportExportValidator` | 领域层负责 v1 版本、字段类型、终态、关联及快照业务校验，复用项目／渠道服务的校验入口 |
| `JsonUtils` | infrastructure/common/utils 下的通用 JSON 树读写、正整数读取及对象遍历；不含项目、渠道、表名、状态、文件上限或业务提示 |
| `ProjectInfoImportExportDao` | 复用当前 DataSource／JdbcTemplate 执行固定表参数化 SQL；不接收任意表列；不决定业务状态 |
| `ProjectInfoImportExportTable`（`infrastructure/common/enums`） | 显式列出八表字段及依赖顺序，数据库新增字段不会自动进入文件 |
| `application/project/model/ProjectImportResponse` | 仅承载新项目和导入数量，由应用层组装，领域层不依赖 Response |

ProjectInfoImportExportBusiness 承担真实文件边界及响应转换，不是只转发调用的包装层；未新增接口、调度器、线程池或数据库表。导出使用 `REPEATABLE_READ` 只读事务；导入事务在领域服务代理入口开始，返回应用层前提交；应用层随后构造 Response。SQL、JSON 解析、约束或引用错误均不被吞掉。Controller 只记录异常类型，不输出 SQL 参数、文件正文或认证资料。

所有管理页同步更新导航脚本版本至 `20261024-transfer1`，避免旧缓存隐藏入口。原有页面业务行为未修改。
