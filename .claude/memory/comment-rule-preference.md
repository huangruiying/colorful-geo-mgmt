# Java 代码生成与注释偏好记忆

- 用户希望 Java 代码生成后自动补充必要的类注释、方法注释、主流程步骤注释。
- Java 专项注释以 `rules/comments/comment-java.md` 为准；Python 专项注释以 `rules/comments/comment-python.md` 为准。
- 通用“少写废话注释”与 Java 主流程步骤注释不冲突：少写翻译代码的注释，但业务阶段、兼容原因、生命周期、兜底逻辑要说明。
- 注释示例应保持最小可识别，不放长业务代码；能用 `xxx` 表达结构时优先压缩示例。
- 用户希望 Java 开发优先使用 Lombok 消除纯样板代码；但领域不可变模型优先使用 `record`，不为使用注解而掩盖业务语义或引入不必要的可变性。
