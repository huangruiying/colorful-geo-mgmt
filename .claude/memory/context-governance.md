# `.claude` 上下文治理记忆

- `.claude` 的核心目标是“按需加载”：入口文件只放路由、索引、触发条件，细节下沉到 `agents/`、`workflows/`、`rules/`、`memory/`。
- 优先使用“引用而非复刻”，避免在多个文件重复维护同一规则。
- 多候选 / 自定义编排细则放在 `workflows/routing-policy.md`，普通单 Agent / 单 Workflow 任务不读取。
- Agent 文件通常按需单文件加载，不做机械压缩；只有锚点错误、职责重复、规则漂移时再改。
- 大段好坏示例会消耗上下文，除非对 AI 执行很关键，否则优先删减、改成最小示例，或引用专题规则。
