# 知乎草稿与公开发布配置

知乎预发布和已有草稿的公开发布使用同一条数据库浏览器会话，不再需要独立 Chrome `profile-dir`。实际发布只操作预发布返回的草稿 ID，不重新提交标题或正文。

## 准备

1. 按 [浏览器登录配置](browser-login.md) 安装 Playwright Chromium，并初始化浏览器登录信息表。
2. 在“浏览器登录管理”中登录知乎，确认该平台的登录状态为 `LOGGED_IN`，数据库记录包含可恢复的 `storage_state`。
3. 确保 Java 服务可访问知乎。会话过期时重新登录，不要通过旧 Chrome 资料目录绕过状态检查。

## 可选配置

页面动作默认等待 30 秒。如需调整，在外置配置中设置：

```yaml
colorful:
  geo:
    publish:
      browser:
        timeout-millis: 30000
```

## 调用与结果

预发布创建草稿后保存平台草稿 ID；人工确认后，实际发布使用该 ID 打开对应知乎草稿并点击发布。两步都从数据库读取知乎登录态。只有重新打开公开文章链接确认成功，才返回公开发布成功；点击后结果不确定时先人工核对，不自动重试。
