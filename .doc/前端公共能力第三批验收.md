# 前端公共能力第三批验收

日期：2026-10-17。范围为分析方案第三批：剩余页面公共请求与已有重复展示能力。未修改后端、导航、CSS、登录状态机、内容发布重试规则或方案编辑流程。

## 实现

- 内容优化、发布记录、浏览器登录、诊断方案接入 AdminHttp.requestJson；所有 8 个业务脚本现已共用请求入口。登录 URL 前缀保留在页面各调用点，取消信号、请求方法和正文保持原值，不增加仅转发的请求包装。
- 诊断方案的重复 allItems 删除，接入已有 AdminPagination.listAll，沿用完整项目/渠道读取。
- publishing/status.js 仅保存两处原本相同的发布状态文字，不决定是否可重试、可删除；各页面未知值回退保持各自原规则。
- shared/format.js 只用于内容与发布记录的日期展示，保留浏览器本地时区与中文24小时制。缺失或非法时间统一为“—”，避免 1970/Invalid Date；诊断原有服务端时间文本不改变。
- 复用 url-utils.js 作为安全网页链接创建入口，publications.js 删除重复 appendWebLink，内容引用、草稿入口共同使用。无效引用仍显示名称，原有 a/span 节点形态保留；新窗口隔离 opener，不插入原始 HTML。
- 微信公众号文章列表入口、已有草稿深链保留及缺失 ID 补充规则不变。未对未接入的平台增加能力。
- 四页显式加载共用依赖，页面和 URL/新展示资源版本 shared3；HTTP 保持 http1，分页保持 lifecycle1，Markdown 保持 md2。未迁移框架或模块系统。

架构复核：共用展示函数无业务状态，发布文案按实际业务域存放；继续使用现有 URL 文件，未新建重复链接组件。没有额外 Controller/接口/数据模型、重试或日志。页面保留交互与提交编排；仅传输解析由共用 HTTP 管理。日期和非法报文的统一展示是本批明确范围内的差异。
