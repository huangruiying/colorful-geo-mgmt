# 前端诊断生命周期第二批验收

日期：2026-10-17。用户确认继续第二批；仅前端诊断任务与报告页面及相应公共读取能力。后端、数据库、模型协议、诊断重做范围和原有正文存储均未修改。

## 完成范围

- 两页改用第一批的 AdminHttp，移除重复 fetch 包装。
- shared/async.js：请求作用域支持取代/取消；读取完成后校验当前归属，过期错误不进入新视图。读轮询完成后才安排下一次；成功且业务仍进行中等 3 秒，网络/429/5xx 提示后等 5 秒重读，其他 HTTP 业务错误停止。
- shared/dialog.js：原生 ESC、遮罩和关闭清理入口统一；业务仍决定提交中是否允许关闭、如何关闭子窗口。最后一个窗口关闭才释放滚动锁；迟到 close 事件不清理已重新打开的窗口。
- shared/pagination.js：逐页读取完整 PageResponse，保留已有筛选和取消信号，中途失败不返回部分选项。任务页已有全量选项读取接入；报告创建由只读前 100 条改为完整分页，跳转参数可选中第 101 条任务。
- 任务页：列表、详情/结果、回答、创建窗口选项和方案预览分别由所属读取生命周期管理；关闭父窗口取消详情与回答等待；保留回答/信息子窗口阅读期间不重绘结果列表的规则。
- 报告页：列表错误不再静默吞掉；详情支持暂时失败恢复；回答增加当前报告/请求校验，旧回答及旧错误不再覆盖新回答。创建提交中 ESC、遮罩与关闭按钮保护一致。
- 两页 pagehide 停止轮询与待完成读取；pageshow.persisted 为仍打开的窗口恢复读取。前端取消仅终止等待，不代表后台诊断或报告生成被取消。
- 页面脚本和新公共资源版本 20261017-lifecycle1，http 保持 http1，Markdown 仍 md2；导航、CSS、报告指标和业务状态字典不改。

## 逐方法注释与结构审计

下表覆盖新增/修改方法及生命周期回调。单阶段方法不另编号，跨网络等待的阶段通过分段、归属校验和必要决策注释表达；本轮没有修改 Java。

| 文件#方法 | 实际阶段及目的 | 方法/阶段说明 | 决策与生命周期检查 | 结果 |
| --- | --- | --- | --- | --- |
| async#createRequestScope | 持有唯一当前请求 → 提供 run/cancel | 说明读取取代与边界 | 不持有业务数据，不取消服务器任务 | 通过 |
| scope#cancel | 先失效标识 → abort 旧等待 | 说明切换/关闭入口 | 先失效可防止 abort 引起旧错误回填 | 通过 |
| scope#run | 取代旧读取 → 发出 signal/isCurrent → 过滤过期错误 | 回调契约要求每次 await 后检查归属 | 当前失败继续暴露，不把新视图错误吞掉 | 通过 |
| async#createPoller | 单独持有请求作用域和计时器 | 说明返回 true 才继续 | 页面的业务状态不下沉到公共层 | 通过 |
| poller#refresh | 清旧计时器 → 当前读取 → 终态停止或延迟续读 | 说明 3/5 秒与错误类型 | 只用于 GET 读取，旧请求不得安排新计时器，不自动重发写请求 | 通过 |
| poller#stop | 清计时器 → 失效并取消当前请求 | 说明旧响应无法恢复 | 关闭、切换、离开页面均使用同一入口 | 通过 |
| pagination#listAll | 解析查询 → 连续分页 → 总数或空页终止 | 说明保留筛选与失败不返部分值 | 每页前后检查取消，保留 PageResponse 数据结构 | 通过 |
| dialog#bind 及三个事件回调 | ESC 校验、遮罩校验、close 清理和滚动锁 | 说明业务条件、子窗口和迟到事件 | 原生 dialog 负责焦点；不替业务决定保存、丢弃或后台取消 | 通过 |
| tasks#loadOptions | 并发读完整方案/渠道 → 校验取消 → 写选项 | 说明创建窗口读取失效 | 保留停用/可用状态展示，不引入新筛选语义 | 通过 |
| tasks#readTaskList | 按当前筛选读取 → 归属校验 → 渲染/判断续读 | 方法说明旧页保护和进行中判断 | 结果只提交给当前筛选，终态结束刷新 | 通过 |
| tasks#openCreate/loadPreview | 取代旧选项/预览读取 → 校验 → 展示当前方案 | 方法说明当前窗口与方案 | 保留创建 requestId 规则、预计次数和提交禁用条件 | 通过 |
| tasks#openDetail/readTaskDetail/loadResults | 清旧详情 → 当前任务与结果读取 → 阅读保护 → 续读判断 | 方法说明整轮信号和子窗口规则 | 过滤变化取消旧轮；关闭任务后不能重启读取 | 通过 |
| tasks#loadAnswer | 取代旧回答 → 归属校验 → 原有正文/引用/用量展示 | 同步说明旧读取失效、正文 Markdown | 保留任务、回答 ID 及窗口校验；失败/原始响应不做 Markdown | 通过 |
| reports#readReportList | 筛选读取 → 当前校验 → 渲染与续读判断 | 说明当前筛选与失败处理 | 列表错误可见，终态停止 | 通过 |
| reports#openCreate | 禁用提交 → 全部分页 → 归属校验 → 候选与预选值 | 说明完整候选及取代规则 | 仍只允许成功/部分失败任务，读取中不允许提交部分结果 | 通过 |
| reports#openDetail/readReportDetail | 取消旧报告/回答 → 读取当前报告 → 更新/续读 | 说明跨报告隔离 | 关闭、切换均失效，不混用上个报告 | 通过 |
| reports#openAnswer | 保存所属报告 → 读取 → 校验 → Markdown/当前错误展示 | 保留正文边界说明 | 旧成功、旧失败、已关闭窗口均不得回填 | 通过 |
| 两页 onClose/pagehide/pageshow | 子窗口清理 → 取消读取/计时器 → 恢复时重读 | 注释区分浏览器等待和服务器执行 | 提交保护仍由页面状态决定，写请求不放进可重读轮询 | 通过 |

架构检查：三个公共文件分别承担异步读取、完整分页、原生窗口行为；两个页面均有真实调用，没有新增 API 转发层或业务模型。HTTP、Markdown 沿用已实现能力。读请求取消由视图所有者发起，写接口不自动取消或重试；业务终态与关闭保护留在页面。页面依赖均显式声明并按顺序加载。
